      How this page works

      There is no server behind it. The page runs odjazd-core, the Rust library behind the odjazd command-line app, compiled to WebAssembly. Every night GitHub Actions downloads Warsaw's GTFS feed, builds three days of the timetable and saves it with rkyv. Your browser downloads that file once and does every search and board itself.

      Timetable: Zarząd Transportu Miejskiego w Warszawie, converted to GTFS by Mikołaj Kuranowski. Times are from the timetable, without live delays.
